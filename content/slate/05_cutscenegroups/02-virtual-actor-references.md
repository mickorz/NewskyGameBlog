# Slate 影像序列器文档 - 虚拟角色引用

## 概述

虚拟角色引用是一项功能，允许用户在仅限于过场动画持续时间内使用虚拟角色引用。该功能通过实例化原始角色引用并可选地将其放置在指定的本地过场动画坐标处来实现，同时禁用原始角色。过场动画完成后，原始角色重新启用，临时实例被销毁。"这一切当然是自动完成的，是一种非常方便的处理预制体角色的方式"。

## 配置选项

所有相关选项都位于所有角色组的检查器中。

## 功能说明

在示例中，目标角色是 Chan，这是一个预制体。虚拟引用线框在场景视图中显示为表示 Chan（角色）实例化位置的表示。此位置和方向也在称为**过场动画空间**的坐标系中表示，这意味着它们与过场动画位置/旋转相关。如果移动过场动画游戏对象，Chan 将在相同的相关位置/旋转处实例化。显示的线条表示与过场动画位置的偏移。

## 参考模式和初始变换组合

### Use Original + Use Original
原始角色将在其原始坐标处使用，无特殊操作。

### Use Original + Use Local
原始角色将被使用，但在过场动画开始时会被传送到过场动画空间中的指定坐标。

### Use Instance + Use Original
将创建并使用实例，但该实例坐标将保持与原始引用相同。

### Use Instance + Use Local
将创建并使用实例，该实例在过场动画开始时实例化在过场动画空间中的指定坐标处。**这是处理预制体角色时的最佳组合**。
