🗺️ 学习路线图
#

初级（入门）
#

目标: 理解Animancer基础概念，能够播放简单动画

  1. ✅ animancer-why - 了解优势
  2. ✅ animancer-playing - 播放动画
  3. ✅ animancer-transitions - 动画过渡
  4. ✅ animancer-fading - 平滑切换

实战项目: 简单的角色移动动画（Idle → Walk → Run）

中级（进阶）
#

目标: 掌握事件、状态机、混合系统

  1. ✅ animancer-events - 动画事件
  2. ✅ animancer-fsm - 状态管理
  3. ✅ animancer-layers - 多层动画
  4. ✅ animancer-mixers - 动画混合

实战项目: 完整的角色控制器（移动 + 战斗 + 交互）

高级（精通）
#

目标: 自定义扩展、性能优化、复杂系统

  1. ✅ animancer-creatingcustomstates - 自定义状态
  2. ✅ animancer-inputbuffer - 输入缓冲
  3. ✅ animancer-controllerstates - Controller集成
  4. ✅ animancer-performance - 性能优化

实战项目: 复杂的战斗系统（连击 + AI + 多武器）
